# Your AI Therapist's Diagnosis

Entry for the [Your AI Therapist's Diagnosis bounty on make.fun](https://make.fun/c/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41).

One funny line — the diagnosis an AI therapist gives its human, in a calm
clinical voice, with the turn landing at the very end:

> Diagnosis: chronic main-character syndrome; prognosis excellent, provided the universe keeps scheduling around you.

## How it works

`main.py` is deterministic and needs nothing but Python 3: it writes exactly
that one line (115 characters, inside the 200-character limit) to
`/output/entry.txt`. No network, no randomness, no input files — the same
bytes on every run.

```sh
python3 main.py
```
